How it is built

Catalog
A zero-dependency Node server reads public catalog pages and turns them into clean JSON for the browser.
Rankings
the AniList API provides trending, top rated, and season lists. Every card carries its MAL id.
Player
hls.js, plus controls I wrote myself: resume, continue watching, and a lock so taps don't skip.
