How it is built

Catalog, parsed not scraped
A zero-dependency Node server fetches and parses public catalog pages server side, so the browser only receives clean JSON.
Rankings, from the source of truth
Trending, top rated, and season tabs come from the AniList GraphQL gateway, which mirrors MAL titles; every card carries its MAL id.
Player, hand-built
HLS via a vendored hls.js with custom controls, resume position, continue-watching, and a locked mode so pocket taps cannot seek.
Phone, the whole studio
Written and tested in Termux on Android: Node, the browser engine for checks, no external screen at any step.
