# ziidxz.github.io

The source of [ziidxz.github.io](https://ziidxz.github.io/): one page and no build step:
`index.html` served with `styles.css`, `tokens.css` and `base.css`.

The register lists eight projects; the sheet opens `termux-browser`; the transcript
under it is real output from `node bin/tbrowse.mjs check index.html`.

Fixes and questions: [open an issue](../../issues).
